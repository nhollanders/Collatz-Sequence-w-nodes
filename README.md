# Collatz-Sequence-w-nodes

## What does it do?
The program will request an input, and once it gets on it will use a finder object to determine the Collatz sequence which gets stored in a separate linked list that uses a third object made from a struct which is the node for each link in the list. After all this is dont it then prints everything to the console and asks if you would like to find another number. Keep in mind there are a ton of significant details I left out but that's the very basis of it.
